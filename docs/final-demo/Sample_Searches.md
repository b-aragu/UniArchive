# Demo Sample Searches

The following sample queries will be used during the live demonstration to highlight the contrast between exact-match capabilities and semantic reasoning.

---

### 1. Operating Systems CAT
*   **Document Content:** "Deadlock occurs when a set of processes are blocked because each process is holding a resource and waiting for another resource acquired by some other process."
*   **Expected Keyword Result:** Query: "deadlock blocked resource" -> Returns document based on exact word matches and stemming.
*   **Expected Semantic Result:** Query: "system freezing due to resource starvation" -> Returns the document based on conceptual similarity.
